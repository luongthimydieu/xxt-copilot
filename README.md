# XXT Copilot —— 学习通题目只读采集与本地整理工具

> 一个运行在 Edge / Chrome 上的浏览器扩展。它把你在学习通（超星）课程中**已经能看到的**章节测验、作业题目和官方答案，采集到本地，方便你统一校对、整理成复习资料。

---

## ⚠️ 先读这段：这是什么，不是什么

**这是「只读采集 + 本地整理」的学习资料工具。**

| 它做 | 它不做 |
| --- | --- |
| 读取已登录课程页面里的目录、题目、官方答案 | ❌ 不自动答题 |
| 把题目/答案整理到本地，供你复习、校对 | ❌ 不自动提交作业或考试 |
| 导出 Markdown / JSON / CSV / 打印视图 | ❌ 不刷课、不刷视频、不模拟点击翻页 |
| 采集失败时记录原因、导出页面存档用于排障 | ❌ 不修改平台上的任何数据 |

**使用前请确认：**

1. 本工具**仅用于个人复习整理**，不得用于抄袭、作弊、代刷课或任何违反学术诚信的行为。
2. 请遵守学习通平台的**用户协议**和所在**学校的相关规定**。如果学校或课程教师明确禁止此类工具，请不要使用。
3. 工具通过你已登录的浏览器会话读取数据，会以正常速度请求页面。虽然内置了串行请求、随机延迟、超时与重试，但**任何自动化访问都存在账号风险（如触发风控、被要求重新验证）**，请自行评估并承担。
4. 请保持默认限速，不要调得过快；建议只采集自己已选修的课程。

> 简单说：**它只是帮你把已经能看到的题目「抄」到本地整理**，所有判断、答题、提交都由你自己在平台上手动完成。

## 功能列表

### 1. 整门课采集
一次扫描整个课程的任务点，按章节串行采集所有章节测验/作业。适合课程复习前一次性把资料整理出来。

### 2. 目录扫描
点击「扫描课程目录」读取课程目录，列出所有章 / 节，并显示每章的任务数。用「全选」「取消选择」批量勾选，也可以单独勾选想采集的章节；**开始采集时只处理已勾选的章节**。重新扫描目录会恢复完整列表，方便重新勾选。

### 3. 单页提取
只想看当前打开的这道题？打开题目页后，在 dashboard 顶栏点「提取当前页」，直接从当前页面（含同源 iframe）提取题目，不发起整门课采集。单页结果会单独显示并标注适配器，点「返回批量结果」即可回到整门课的结果。

### 4. 官方答案收集
题目页里平台自带的「正确答案」会被一并读取（能看到官方答案的页面才能收集到）。看不到答案的题目会留空，由你在校对阶段手动补充。

### 5. 在线校对
采集完成后在 dashboard 的题目表格里逐题检查、修改「正确答案」，支持按章节 / 题型 / 是否已有答案筛选，以及按题干搜索。

### 6. 导出
- **Markdown（含答案）/ Markdown（不含答案）**：按章节和题型分组，方便背诵自测；不含答案版隐藏答案。
- **JSON**：完整结构化数据，方便备份或二次处理。
- **CSV（Excel）**：带 BOM，Excel 可直接打开，适合做表格整理。
- **打印视图**：新窗口打开排版好的 A4 HTML（可勾选「打印包含答案」），可用浏览器「打印 → 另存为 PDF」，或复制到 Word 使用（见[已知限制](#已知限制)）。

### 7. 页面存档排障
某个页面采集失败或解析为空时，点顶栏「导出页面存档」一键导出页面结构存档：包含当前页面 HTML、同源帧信息、目录、运行日志等，发给维护者就能定位解析问题。用法见 [docs/SNAPSHOT.md](docs/SNAPSHOT.md)。

### 8. 进度、日志与失败诊断
采集全程有进度条、统计卡片和日志。每个失败任务都会记录**失败原因和源 URL**，在任务状态区可以直接看到哪一章哪一题没采到。

## 与旧油猴脚本方案的区别

很多同学用过早期的油猴（Tampermonkey）脚本。旧方案的套路通常是：**模拟点击「下一节」按钮**，把整门课当成一个视频播放列表，靠**猜测页面底部任务栏**的位置来判断有没有测验。课程页面一改版、任务栏位置一变，就会漏章、漏任务。

XXT Copilot 换了思路：

| 对比项 | 旧油猴脚本方案 | XXT Copilot |
| --- | --- | --- |
| 任务发现方式 | 模拟点击「下一节」，猜底部任务栏 | 直接请求平台自己的接口 `/mooc-ans/knowledge/cards`，拿到真实的任务点列表 |
| 题目页读取 | 依赖页面实际跳转、等待渲染 | `fetch` 拉取题目页 HTML，用 `DOMParser` 解析 |
| 页面结构变化 | 改版即失效，容易漏章 | 多适配器依次尝试（markitem / timu / score-review / phone / questionli / text），按质量评分选最优，并记录警告 |
| 失败表现 | 静默漏题，不知道少了什么 | 每个失败任务都有原因分类 + URL + 日志，还能导出页面存档 |
| 采集控制 | 不容易暂停、限速 | 可暂停 / 继续 / 停止，串行请求 + 随机延迟 + 超时 + 有限重试 |
| 数据落地 | 通常只在页面上 | 本地存储 + Markdown / JSON / CSV / 打印视图导出 |

> 一句话：**不再「模拟人点页面」，而是「按平台自己的数据接口取数据」**。请求更少、更稳，也更方便说明哪里出了问题。

## 架构图

### 数据流（一次整门课采集）

```text
[① 目录扫描] content/frames.js
  读取学习通课程页里的章节目录，得到章节（entry）列表
        │
        ▼
[② 任务发现] content/net.js
  对每个章节请求平台接口 /mooc-ans/knowledge/cards
  得到该章节的任务点（测验 / 作业）及 workId 等参数
        │
        ▼
[③ 读取题目页] content/net.js
  fetch 拉取任务页 HTML
  （串行请求 + 随机延迟 + 超时 AbortController + 有限重试 + 指数退避）
  失败：记录原因分类 + URL，继续下一个任务
        │
        ▼
[④ 多适配器解析] content/parsers.js
  DOMParser 解析 HTML → markitem / timu / score-review / phone / questionli / text 等适配器
  → 质量评分选最优结果（题干为空、选项缺失等会记 warnings）
        │
        ▼
[⑤ 本地整理与导出] dashboard/
  题目表格在线校对 → Markdown / JSON / CSV / 打印视图
  失败排障 → 导出页面存档 JSON
```

### 组件结构

```text
浏览器（Edge / Chrome，Manifest V3）
│
├─ 学习通页面（*.chaoxing.com / *.xuexitong.com / *.edu.cn，只读）
│   ├─ 课程章节页 ──→ 目录扫描（content/frames.js）
│   └─ 题目 / 作业页 ──→ fetch HTML + DOMParser 解析
│
├─ manifest.json
│     声明权限（storage）与注入域名（学习通 / 教育网）
│
├─ background.js（Service Worker）
│     点击扩展图标打开控制台 · 记录当前学习通标签页 · 跨域请求兜底
│
├─ content/（注入学习通页面，只读）
│   ├─ frames.js    同源帧遍历 / 目录扫描 / 页面存档快照
│   ├─ net.js       串行限速请求 / cards 任务发现 / 题目页 URL 构造
│   ├─ parsers.js   多适配器题目解析 + 质量校验
│   └─ content.js   任务编排 / 消息协议 / 单页提取
│
├─ dashboard/（扩展本地页，即「控制台」）
│   └─ 扫描 / 开始 / 暂停 / 继续 / 停止 · 进度与日志 · 题目校对
│      导出 Markdown / JSON / CSV / 打印视图 · 导出页面存档
│
├─ chrome.storage.local / session
│     设置、采集状态、目标标签页（只在本机，不同步）
│
└─ 本地文件
       Markdown · JSON · CSV · 打印视图（PDF / Word）· 页面存档 JSON

content/ 与 dashboard/ 之间通过 chrome.runtime 消息
（XXT_PING / XXT_SCAN / XXT_START / XXT_GET_STATE / XXT_SNAPSHOT …）交互。
```

> 全程没有远程服务器：不登录任何第三方账号、不上传采集结果、不加载远程脚本。数据只存在你自己的电脑上。

## 使用步骤

1. **登录并打开课程页**：在浏览器里登录学习通，进入要采集的课程，打开任意一个章节页面（能显示目录的那一页）。保持这个标签页打开。
2. **打开 dashboard**：点击浏览器工具栏上的 XXT Copilot 图标，会自动打开扩展的控制台（dashboard）页面。顶栏有「重新连接」「提取当前页」「设置」「导出页面存档」。
3. **确认连接**：顶栏显示课程名和「已连接」即正常；如果提示需要先打开学习通课程页，按提示打开后点「重新连接」。
4. **扫描目录**：点击「扫描课程目录」，等待 2～5 秒。核对列表里的章节数是否与课程目录一致；默认全选，也可以点「取消选择」后只勾选需要的章节——**开始采集后只采集勾选的章节**。重新扫描目录可恢复完整列表。
5. **按需调整设置**：点「设置」打开「采集设置」，可改最小/最大请求间隔、单请求超时、失败重试次数、单任务最大翻卡数，点「保存设置」生效。网络不好时把延迟和超时调大一些更稳。
6. **开始采集**：点击「开始采集」，观察进度条、统计卡片和日志。采集是串行的，请耐心等待；期间可以「暂停」「继续」或「停止」。
7. **处理中断**：如果遇到验证码或登录失效，工具会**暂停并提示原因**，不会强行继续。处理完（手动通过验证 / 重新登录并刷新课程页）后回到 dashboard 点「继续」或「重新连接」。
8. **单页提取（可选）**：只想提取当前打开的题目页？保持该页打开，在 dashboard 点顶栏「提取当前页」；结果区会单独显示单页提取结果（含适配器与警告），点「返回批量结果」可回到整门课的结果。
9. **校对题目**：结果区按「章节」「题型」「已答」筛选，或用搜索框搜题干，逐题检查「正确答案」；直接在格子里改，按回车或点开别处自动保存（成功会提示「答案已保存」）。
10. **导出资料**：在「导出」区按需点 Markdown（含答案）/ Markdown（不含答案）/ JSON / CSV（Excel）/ 打印视图（可勾选「打印包含答案」）。导出文件会保存到浏览器的默认下载目录，文件名形如 `xxt-<课程名>-题目-含答案-<日期时间>.md`、`xxt-<课程名>-题目-<日期时间>.json` / `.csv`。
11. **遇到失败**：在日志和任务状态区查看失败原因；需要进一步排查时，按 [docs/SNAPSHOT.md](docs/SNAPSHOT.md) 导出页面存档并发给维护者。

> 第一次使用真实环境时，建议按 [docs/QA-CHECKLIST.md](docs/QA-CHECKLIST.md) 逐项验证一遍。

## 限速、超时与重试

工具刻意做得「慢」，目的是尽量不打扰平台、降低账号风险。默认参数：

| 设置项 | 默认值 | 含义 | 调整建议 |
| --- | --- | --- | --- |
| 最小延迟 `minDelay` | `600` ms | 相邻两次请求之间的最小间隔 | 不要低于 500 ms；网络差或平台敏感时调大到 1000+ |
| 最大延迟 `maxDelay` | `1500` ms | 随机延迟的上限（实际间隔在最小～最大之间随机） | 保持比 minDelay 大，随机间隔更自然 |
| 单请求超时 `timeout` | `20000` ms | 一次请求最多等多久，超时即中止 | 校园网慢时调到 30000；调小可更快发现异常（实际请求下限为 3000 ms） |
| 失败重试 `retries` | `2` 次 | 超时 / 网络错误时最多再试几次 | 保持默认即可；频繁失败更可能是网络或登录问题 |
| 单任务翻页上限 `maxCards` | `80` | 一个任务点最多翻多少张卡（题目页） | 题量特别大的课程可适当调大 |

> 设置项有生效范围：`minDelay` / `maxDelay` 为 0～60000 ms；`timeout` 实际请求下限为 3000 ms（界面允许填 1000，但更小的值会按 3000 生效）；`retries` 实际最多 5 次；`maxCards` 实际最多 200 张。设置保存在浏览器本地存储中，下次打开 dashboard 仍然生效。

行为说明：

- **串行请求**：同一时间只发一个请求，不会并发轰炸服务器。
- **随机延迟**：每次请求之间等待一个随机时长，避免固定节奏。
- **超时中止**：使用 `AbortController`，卡住的请求不会无限等待。
- **有限重试 + 指数退避**：失败后等待一段时间再重试，重试次数用完就记为该任务失败并继续后面的任务，不会卡死在某一页。
- **危险信号暂停**：识别到验证码、登录失效、网络异常时暂停采集并在界面提示，处理完毕后由你手动继续。
- **失败可诊断**：每个失败任务记录原因和源 URL；日志保留最近 300 条，可随时查看。

## 常见问题

### 点了扩展图标没反应 / 没打开 dashboard？
确认扩展已在扩展管理页启用，并且没有被浏览器禁用。刷新页面后重试；仍不行就回扩展管理页点「重新加载」，再点图标。

### 提示「请先打开学习通课程页」/ 连接断开？
dashboard 需要在一个**已打开的学习通课程标签页**上工作。请打开课程章节页，然后回 dashboard 点「重新连接」。如果学习通页面刷新过，内容脚本会重新加载，也需要重新连接。

### 登录失效了怎么办？
日志里会出现「学习通登录状态已失效，请重新登录后继续」这类提示。重新登录学习通并刷新课程页面，再回 dashboard 点「重新连接」。工具不会在不登录的情况下继续硬请求。

### 弹出验证码 / 页面要求人机验证？
日志会提示「页面要求验证码/安全验证，请手动完成验证后点“继续”」。按提示**手动**完成验证即可，工具不会也不应该自动绕过验证码。验证完成后回到 dashboard 点「继续」；如果仍然失败，刷新学习通页面后重新连接再试。

### 扫描目录失败，或目录是空的？
- 确认当前标签页是**课程章节页**（能看到左侧/页内目录），不是课程首页、作业列表或成绩页；
- 等页面完全加载后再点「扫描课程目录」；
- 刷新学习通页面后重新连接再扫描；
- 仍然失败请查看日志，并导出页面存档反馈。

### 某一章采集结果为空？
可能原因：该章没有测验/作业任务点（纯视频或文档章节）、该章任务点不在接口返回范围内、或页面结构版本暂未被适配。先看该章任务数是否为 0，以及日志里是否有解析失败记录；如果是解析问题，请按 [docs/SNAPSHOT.md](docs/SNAPSHOT.md) 导出页面存档。

### 题目采到了，但不显示答案？
平台只在部分页面/部分状态下提供官方答案，看不到的答案无法收集，会留空。你可以在校对区手动补上，再导出「含答案」版本。也可以在该题页面点「提取当前页」看看是否能取到答案。

### 某个任务失败了，怎么知道原因？
任务状态区会显示该任务的状态与失败原因；日志区有对应的 `warn` / `error` 记录和源 URL。常见的失败原因包括：

- `请求超时`：网络慢或页面太久没响应；
- `网络请求失败` / 后台请求失败：断网、代理或跨域问题；
- `请求过于频繁（429）`：触发平台限流，应暂停一段时间、降低频率；
- `请求被拒绝（403）`：扩展会先自动尝试其它候选地址和隐藏 iframe 导航兜底；如果所有方式都失败，会记录每个候选地址的结果。连续 3 个任务都 403 时会自动暂停。处理办法见下面「遇到 403 怎么办？」；
- `学习通登录状态已失效`：重新登录并刷新页面；
- `页面要求验证码/安全验证`：手动完成验证后继续；
- `HTTP 4xx / 5xx`：目标页面不存在或服务端异常；
- `cards 响应中找不到 attachments` 等解析错误：页面结构可能已改版，请导出页面存档反馈。

先确认是不是登录、验证码、网络或超时问题，再决定重试还是反馈。

### 遇到 403 怎么办？
1. 先在浏览器里**手动**打开同一章的章节测验，确认页面能正常访问（排除登录失效/课程被锁）；
2. 如果能打开，回到 dashboard 点「继续」，扩展会继续尝试其它候选地址和 iframe 兜底；
3. 如果仍然 403：在设置里把「最小/最大请求间隔」调大（例如 1500 / 3000ms），刷新学习通页面、重新连接后再试；
4. 还不行就把**日志里 `本任务失败` 那一行**（包含尝试过的地址和各自的错误）截图发回，并导出该章节的页面存档。维护者可以据此确认真实可用的题目页 URL。

### 采集速度很慢，正常吗？
正常。串行请求 + 随机延迟意味着每章可能要几十秒、整门课几分钟。这是为了降低平台压力与账号风险，不建议把延迟调得过低。

### 会不会自动提交作业或考试？
**不会。** 扩展只读取页面和接口数据，在本地整理；从不点击提交、交卷、保存作业等按钮，也不会修改平台数据。

### 只想提取当前这道题？
保持题目页打开，在 dashboard 顶栏点「提取当前页」。结果区会切换到单页提取结果（标题旁标注适配器，并可能显示警告）。点结果区右上角的「返回批量结果」即可回到整门课采集的结果。

> 注意：「提取当前页」只对**具体的章节测验/作业题目页**有效。如果当前是课程目录/章节列表页，工具会提示“当前页面不像题目页”，不会把目录行当成题目；请先点开那个测验再提取。

### 提取当前页得到的是“章节名 + 已完成”，不是题目？
这是旧版本把课程目录行误判成题目的问题，v0.1.2 已加入页面级证据门槛：必须存在题目容器、题型标签、答案或至少两行选项才会解析。若仍然出现，请导出页面存档反馈。

### 页面存档是什么，怎么发给维护者？
见 [docs/SNAPSHOT.md](docs/SNAPSHOT.md)。简要流程：在出错页面上打开 dashboard → 点顶栏「导出页面存档」→ 下载 `xxt-snapshot-*.json` → 连同日志、章节名一起反馈。

## 隐私与安全

- **数据只在本机**：设置保存在浏览器本地存储 `chrome.storage.local`，采集状态保存在扩展页面/学习通页面的内存中（刷新页面即重置）；导出的文件只写到你的默认下载目录。
- **无遥测、无统计上报**：扩展不包含任何埋点、统计、崩溃上报。
- **无远程代码、无外部依赖**：所有脚本都打包在扩展目录内，不加载 CDN、不发 `eval`，符合 MV3 的内容安全策略（CSP）。
- **权限最小化**：只申请运行所必需的权限：`storage`（本地保存设置与状态），以及学习通 / 教育网域名的访问权限（`*.chaoxing.com`、`*.xuexitong.com`、`*.edu.cn`），不会申请无关网站权限。导出文件由控制台页面直接触发浏览器下载，不需要「下载管理」权限，也没有申请 `tabs`、`scripting` 等权限。完整权限表见 [INSTALL.md](INSTALL.md)。
- **不收集账号密码**：扩展复用你浏览器里已有的登录态，不读取、不保存你的密码，也不会把会话或采集数据发送到任何第三方服务器。
- **存档文件含隐私**：页面存档会包含课程页面 HTML 和日志，可能带有课程内容、题目，甚至页面上的姓名、学号等信息。**请只私下发给可信的维护者，不要上传到公开网盘、论坛或群聊**。反馈前可以先搜索并删除不想暴露的信息。

## 已知限制

- **加密字体页面**：部分课程页面用自定义字体做反爬（页面文字在源码里是乱码/私有编码），纯 HTML 解析可能读不对。工具检测到这类页面时会给出「页面使用了加密字体，部分文字可能是乱码」的警告；遇到后欢迎导出页面存档反馈，以便增加 DOM 兜底适配。
- **作业列表里的非任务点作业暂不采集**：当前只采集课程章节任务点内的测验/作业；作业列表里独立存在、不属于任何任务点的作业不在此版本范围内。
- **Word / PDF 用打印视图输出**：暂不直接生成 `.docx`。打印视图依赖浏览器的打印功能：用「打印 → 另存为 PDF」输出 PDF，或复制打印视图内容到 Word 中排版；如果浏览器拦截了新窗口，需要允许扩展打开窗口后重试。
- **答案完整性取决于平台**：平台未展示的官方答案无法凭空获得；部分题目需要你手动校对。
- **图片以链接形式记录**：导出的 Markdown 里图片可能引用学习通上的远程地址，需要登录态/联网才能显示，链接也可能过期。
- **平台改版可能失效**：学习通页面结构调整后，适配器可能需要更新，届时会出现解析为空或失败。
- **规模限制**：章节/任务特别多的课程采集耗时较长；采集结果建议及时导出保存。
- **仅桌面端 Chromium 浏览器**：不支持手机浏览器。
