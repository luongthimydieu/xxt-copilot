# 发布到 Edge 加载项 / Chrome 应用商店

> 本文是操作清单，不是保证。**先读第 0 节的风险**：这类“学习通题目整理”工具在商店审核中有被拒绝的可能，务必 truthful 描述，不要为了过审而隐瞒功能。

## 0. 先看风险与合规

### 可能触发审核的问题

Microsoft Edge 加载项商店[开发人员策略](https://learn.microsoft.com/zh-cn/legal/microsoft-edge/extensions/developer-policies)里，与本扩展相关的条款包括：

- **1.1.1 单一用途**：扩展必须有一个明确、狭窄的用途；
- **1.1.2 准确描述**：不能误导用户，功能必须如实披露；
- **1.2 安全 / 1.6 权限最小化**：只申请必要权限并逐项说明理由；
- **1.5 个人信息**：如果访问/收集个人信息，必须有隐私政策并如实披露；
- **2.8 禁止内容**：不得提供未经授权的网站内容访问（绕过付费墙/登录限制），不得通过自动化操纵平台功能；
- 平台自身的用户协议可能也不允许自动化抓取。

Chrome Web Store 的[计划政策](https://developer.chrome.com/docs/webstore/program-policies/policies)同样包含单一用途、权限最小化、欺骗性行为、学术诚信等审核点。

### 本扩展的定位（如实说明即可，不要夸大也不要隐瞒）

- 只读取**用户自己已登录、已有权访问**的页面与同站点接口；
- 不自动答题、不自动提交作业/考试、不刷课、不修改平台数据；
- 所有数据在本地处理，没有服务器、没有遥测；
- 用户自己决定是否导出、导出什么。

**结论**：审核可能通过，也可能被判定为“协助学术不端/自动化访问第三方平台”而拒绝。请做好两套准备：**商店 + GitHub Releases 侧载**。被拒不要反复换皮重提，先按拒绝理由申诉或调整。

### 不要做的事

- 不要在描述里写“自动答题/刷课/代做/破解”；
- 不要隐藏“会访问学习通页面并读取内容”的事实；
- 不要在包里带任何真实课程题目、学号姓名等用户数据（本项目的 `tools/fixtures/` 含有真实课程页面，**绝不能打进商店包**）；
- 不要使用未授权的第三方题库 API 或把用户数据传到自己的服务器（当前版本没有，保持这一点）。

## 1. 准备清单

### 账号

| 商店 | 账号 | 费用 | 审核时长（参考） |
| --- | --- | --- | --- |
| Microsoft Edge 加载项 | 微软账号 + 合作伙伴中心 Edge 计划，个人账号即可 | **免费**（官方文档明确“提交扩展不收取注册费”） | 认证最多 7 个工作日 |
| Chrome 应用商店 | Google 开发者账号 | 一次性注册费（以注册页显示为准，通常 5 美元） | 几天到几周 |

### 已为你生成的材料

- `icons/icon16.png`、`icon32.png`、`icon48.png`、`icon128.png`：扩展图标（已写入 manifest）；
- `store-assets/logo-300.png`：商店 logo 300×300（Edge 要求至少 128×128，建议 300×300）；
- `store-assets/promo-small-440x280.png`、`promo-large-1400x560.png`：Edge 可选促销图；
- `PRIVACY.md` + `docs/privacy-policy.html`：隐私政策（**必须替换占位符并托管到公网 URL**）；
- `tools/package-store.ps1`：生成“只含运行文件”的商店 zip（排除 tools/docs/fixtures/存档）；
- 本文第 4 节的商店文案、权限理由、认证测试说明，可直接粘贴。

### 你还需要做的

1. **替换隐私政策占位符**：开发者名称、联系邮箱、生效日期（`PRIVACY.md` 和 `docs/privacy-policy.html`）；
2. **托管隐私政策**：GitHub Pages / 自己的网站 / Notion 公开页等，拿到一个可公开访问的 HTTPS URL；
3. **截图**（Chrome 至少 1 张，Edge 建议 3–5 张）：
   - 尺寸：**1280×800** 或 640×480；
   - 推荐画面：① 扫描目录并勾选章节；② 采集进度 + 结果统计；③ 题目校对表格（含选项/答案）；④ 导出设置/打印视图；
   - **打码**课程名、姓名、学号、头像等个人信息；用你已正常工作的真实课程截图最有说服力；
4. 准备**支持邮箱**（可以就是你的常用邮箱）和可选的**官网/GitHub 地址**；
5. 决定是否开源：开源能提高审核信任度（审核员可读代码），但也会被他人复用；如果要开源，先加 `LICENSE`（如 MIT）。

### 生成干净的商店包

```powershell
pwsh -File tools/package-store.ps1 -Version 0.1.4
# 输出：dist/store/xxt-copilot-0.1.4-store.zip
```

上传前确认 zip **根目录直接是 manifest.json**，且**不包含** `tools/`、`docs/`、`store-assets/`、任何 `xxt-snapshot-*.json`。

## 2. Microsoft Edge 加载项发布步骤

官方文档：[发布 Microsoft Edge 扩展](https://learn.microsoft.com/zh-cn/microsoft-edge/extensions/publish/publish-extension)

1. **注册开发者账号**
   - 用微软账号登录 [合作伙伴中心 Edge 仪表板](https://partner.microsoft.com/dashboard/microsoftedge/public/login)；
   - 进入“帐户设置 → 程序 → Microsoft Edge → 开始使用”，填写国家/地区、个人账号、发布者显示名称、联系方式，接受开发者协议；
   - 个人账号验证较快（验证发布者名称可用性）；等待微软验证邮件。

2. **创建新扩展并上传包**
   - 合作伙伴中心 → Edge → “创建新扩展”；
   - 上传 `dist/store/xxt-copilot-0.1.4-store.zip`；
   - 等待包校验通过（若报错，多半是 manifest/图标/字段问题）。

3. **可用性（Availability）**
   - 可见性先选 **Public**（公开）；市场按需选择（可先选“全部市场”，或只选中国）；
   - 保存继续。

4. **属性（Properties）**
   - 类别：**生产力（Productivity）** 或 **教育（Education）**；
   - 网站：你的 GitHub 仓库/介绍页（可选）；
   - 支持联系人：你的邮箱或支持页面；
   - 成人内容：否。

5. **隐私（Privacy）**（新 UI 为独立页面）
   - **单一用途说明**（可直接用）：

     > XXT Copilot 是一个只读的课程资料整理工具。它在用户已登录的学习通课程页面中，读取用户自己有权访问的章节测验/作业题目及页面已展示的解析，整理成可按章节导出（Markdown/JSON/CSV/打印）的复习资料。扩展不自动答题、不自动提交作业或考试，不修改平台数据；所有处理均在本机完成，不上传任何数据。

   - **权限理由**：
     - `storage`：保存用户的请求间隔/超时/重试等设置；
     - `host_permissions: *.chaoxing.com / *.xuexitong.com / *.edu.cn`：在用户主动打开的学习通页面读取页面内容、请求同一站点接口，实现题目整理；不用于任何其它网站。
   - **远程代码**：否（Manifest V3，所有代码在包内）。
   - **数据使用**：本扩展不上传/不收集数据；页面内容仅在本地内存处理。隐私政策 URL 填你的托管地址。
   - **隐私政策 URL**：第 1 节托管好的 URL。

6. **Microsoft Store 一览（每种语言）**
   - 扩展名称、简短说明（来自 manifest，**改 manifest 后需重新上传包**）、详细说明（≥250 字符，见第 4 节）；
   - 上传 **扩展徽标 300×300**；
   - 可选上传 440×280 小促销图、1400×560 大促销图；
   - 上传 **截图 1280×800**（建议 3–5 张）；
   - 搜索词：见第 4 节（≤7 个）。

7. **认证测试说明**（Submission Options → Notes for certification，见第 4 节）
   - 重点解释“没有测试账号”的原因，并提供 **demo 模式**验证路径：
     `chrome-extension://<扩展ID>/dashboard/dashboard.html?demo=1`
   - 说明扩展只读、无自动提交、无网络上传。

8. **提交并等待认证**
   - 状态会经历“认证中 → 在 Microsoft Store 中”；
   - 认证最长约 7 个工作日；被拒会给出理由，可在 7 天内按流程申诉/修改后重提。

## 3. Chrome 应用商店发布步骤（可选）

1. 注册 Chrome Web Store 开发者账号（一次性注册费，具体金额以注册页为准），开启两步验证；
2. 开发者控制台 → “新增项目” → 上传同一个 `-store.zip`；
3. 填写商品详情：名称、摘要（≤132 字符）、详细说明、类别（生产力/教育）、语言、图标（128×128）、截图（1280×800 或 640×480，至少 1 张）；
4. 隐私权实务：单一用途说明、权限理由（同第 2 节）、数据使用声明（不收集/不上传）、远程代码（否）、隐私政策 URL；
5. 分发范围：公开、所有地区或指定地区；
6. 提交审核。Chrome 对“抓取学习平台题目与答案”的容忍度通常比 Edge 更低，**被拒概率不低**，不要把 Chrome 当作唯一发布渠道。

## 4. 商店文案（可直接使用）

### 简短说明（≤132 字符）

> 只读整理学习通课程中已可见的题目与解析，按章节校对并导出 Markdown/JSON/CSV/打印版。不自动答题、不提交。

### 详细说明（≥250 字符）

> XXT Copilot 是一个面向个人复习的课程资料整理工具，适用于 Microsoft Edge / Chrome。
>
> 你在学习通（超星/泛雅）课程中已经能看到的章节测验、作业题目和解析，可以按章节扫描、整理并导出为 Markdown、JSON、CSV 或 A4 打印视图，方便统一校对和离线复习。
>
> 主要功能：
> • 扫描课程目录，按章勾选需要整理的内容；
> • 串行、限速地读取题目页，支持暂停/继续/停止，失败任务有明确原因记录；
> • 题目表格支持按章节、题型、是否已有答案筛选，可搜索题干、手动校对答案；
> • 导出含/不含答案的 Markdown、JSON、CSV，以及可直接打印为 PDF/Word 的打印视图；
> • 出错时可导出“页面存档”，便于定位解析问题。
>
> 重要说明：
> • 本扩展只读取你已登录、已有权访问的页面内容，所有数据只在本机处理，不上传任何服务器，无遥测、无广告；
> • 不自动答题，不自动提交作业或考试，不刷课，不修改平台数据；
> • 与超星、学习通、泛雅及各学校无隶属或合作关系；请遵守所在学校规定与平台用户协议，仅用于个人复习整理。

### 权限理由（逐条）

- `storage`：保存请求间隔、超时、重试次数等本地设置。
- `host_permissions`（chaoxing/xuexitong/edu.cn）：仅在用户主动打开的学习通课程页面上读取页面内容与同站点数据，用于整理题目；不访问其它网站。

### 认证测试说明（Notes for certification）

> 本扩展不需要独立服务器。由于功能只针对用户自己的学习通账号与已选修课程，我们无法提供可共享的测试账号（涉及个人课程与隐私）。请通过以下 demo 模式验证界面与导出功能，不需要登录：
>
> 1. 加载扩展后打开 `chrome-extension://<扩展ID>/dashboard/dashboard.html?demo=1`；
> 2. 点击“扫描课程目录”→“开始采集”，可看到完整的进度、日志、结果表格、筛选/搜索、答案校对、导出（Markdown/JSON/CSV/打印）；
> 3. 点击“提取当前页”可验证单页提取流程（demo 数据）；
> 4. 扩展不发起任何上传请求，不自动答题/提交；所有请求均限定在用户自己的学习通页面内，串行限速并带超时重试。
>
> 代码全部包含在安装包中（Manifest V3，无远程代码、无 eval），可静态审查。

### 搜索词（≤7 个，逗号分隔）

> 学习通, 超星, 课程题目, 复习资料, 题目导出, 学习资料整理, 错题整理

## 5. 被拒了怎么办

1. **先读拒绝理由**，不要盲目重复提交；按官方申诉流程说明“只读、本地、不自动提交、无数据传输”；
2. 如果拒绝原因是“名称/描述误导”，修改名称与文案（例如把“学习通题目采集器”改成“XXT Copilot · 课程资料整理”，把“答案”改成“页面已展示的解析”）；
3. 如果拒绝原因是“自动化访问/学术诚信”，商店渠道基本很难通过，**转 GitHub Releases + 侧载**：
   - GitHub 建公开仓库，上传源码与 `-store.zip`；
   - README 写清楚安装方式（`edge://extensions` → 开发人员模式 → 加载解压缩的扩展）；
   - 用 GitHub Pages 托管隐私政策与使用说明；
4. 不建议把扩展上传到非官方扩展站或打包站，容易被二次打包/挂马。

## 6. 版本更新流程

1. 修改代码 → 更新 `manifest.json` 的 `version`；
2. 跑 `tools/final-check.ps1`（离线回归测试）与 `tools/package-store.ps1`；
3. 合作伙伴中心 → 该扩展 → 上传新包 → 重新提交认证；
4. 商店通常会在 1–7 个工作日内完成增量审核。
