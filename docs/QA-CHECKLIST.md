# 首次真实环境验收清单

本清单用于在**真实学习通环境**里第一次完整验证 XXT Copilot，确认安装、采集、校对、导出、排障各个环节都正常。建议由维护者或参与测试的同学按顺序执行。

- 测试前请先阅读 [INSTALL.md](../INSTALL.md) 完成安装；
- 请使用**自己已选修的课程**或测试课程，并用**默认限速**，不要为了求快调低延迟；
- 每一项都勾选「通过 / 失败」，失败时在「验收记录」里写清现象并附日志；
- 需要提交页面存档时，按 [SNAPSHOT.md](SNAPSHOT.md) 操作。

## A. 安装与连接

- [ ] **A1 加载扩展**：按 [INSTALL.md](../INSTALL.md) 侧载本目录，扩展管理页显示「XXT Copilot - 学习通题目采集器」、版本 `0.1.0` 且无报错。
  - 预期：扩展已启用，无红色错误提示。
- [ ] **A2 打开控制台**：打开学习通课程章节页，点击工具栏扩展图标。
  - 预期：自动打开 `chrome-extension://<扩展ID>/dashboard/dashboard.html`，标题为「XXT Copilot · 控制台」。
- [ ] **A3 PING 连接成功**：dashboard 加载后顶栏连接状态变为「已连接」，并显示课程名。
  - 预期：能看到课程名（不是「未连接课程」），也没有错误横幅。
- [ ] **A4 空状态提示**：先关闭学习通标签页，再刷新 dashboard。
  - 预期：显示「请先打开学习通课程章节页」及引导文字，状态为「未连接」，不崩溃、无脚本报错。
- [ ] **A5 重新连接**：重新打开学习通课程章节页，回 dashboard 点「重新连接」。
  - 预期：恢复显示课程名，连接状态为「已连接」。
- [ ] **A6 未进入课程时的提示**（可选）：打开学习通首页或非课程章节页，再重新连接。
  - 预期：能连上但提示「页面已连接，但未检测到课程目录」，引导进入具体课程章节页。

## B. 目录扫描

- [ ] **B1 扫描章节**：点击「扫描课程目录」，等待 2～5 秒。
  - 预期：出现章节列表，按顺序排列，每行显示「任务 x/y · knowledgeId」与状态徽标；扫描提示变为「共 N 个章节 · 已勾选 N 个 · 任务点 M 个」。
- [ ] **B2 数量核对**：把列表章节数与学习通课程目录里的章/节数量对照。
  - 预期：**数量一致，无漏章、无重复**；记录实际数量：______ 与页面目录数量：______。
- [ ] **B3 任务数**：抽查 2～3 个有测验的章节，确认任务数大于 0；纯视频章节允许为 0。
  - 预期：有章节测验的章节能发现任务，数量与页面一致。
- [ ] **B4 全选/取消选择**：点击「全选」「取消选择」。
  - 预期：勾选状态正确联动，扫描提示里的「已勾选」数量同步变化。
- [ ] **B5 只选一章**：点「取消选择」后只勾选一个章节。
  - 预期：「开始采集」按钮变为「开始采集（1 章）」；后续采集只处理这一章，重扫目录后可恢复全选。
- [ ] **B6 未扫描时**：刷新 dashboard 后不扫描目录，直接看按钮状态。
  - 预期：「开始采集」不可用（灰色），提示需要先扫描目录。

## C. 单章采集

- [ ] **C1 开始采集**：只勾选 1 个有测验的章节，点「开始采集」。
  - 预期：状态变为运行中，进度条、统计卡片、日志开始更新；日志出现「开始采集：1 个任务点…」及请求间隔/超时/重试参数与任务进度；任务状态和最终结果中**不出现未勾选章节**。
- [ ] **C2 采集完成**：等待该章采集结束。
  - 预期：章节状态变为「完成」，无失败任务；统计里题目数大于 0，日志出现「采集完成：…」。
- [ ] **C3 题目核对**：打开学习通对应章节测验，与结果区题目逐题对照（抽 3～5 题）。
  - 预期：题干、选项、题型一致，顺序合理，无乱码。
- [ ] **C4 无任务章节**：勾选一个纯视频/无测验章节采集。
  - 预期：该章状态为「无任务」，日志说明未发现测验任务，不影响其他章节。
- [ ] **C5 失败任务展示**：如果该章有失败任务，检查任务状态区与日志。
  - 预期：能看到失败原因（如请求超时/HTTP 状态码/解析为空）与源 URL，而不是静默跳过。

## D. 官方答案收集

- [ ] **D1 有答案的页面**：采集一个页面上能看到「正确答案」的章节测验。
  - 预期：对应题目「正确答案」列有值，「已答」筛选能筛出这些题。
- [ ] **D2 无答案的页面**：采集一个看不到答案的页面（如未作答的测验）。
  - 预期：答案列为空并标记为未答，不报错；不伪造答案；结果表「质量 / 适配器」列可能出现「页面未显示答案」提示。

## E. 单页提取

- [ ] **E1 打开单个题目页**：在学习通打开一个测验/作业题目页，保持当前页。
- [ ] **E2 提取当前页**：在 dashboard 顶栏点击「提取当前页」。
  - 预期：结果区切换为单页提取结果，标题旁出现「单页提取 · 适配器 xxx」徽标，并显示提取到的题目；按钮短暂显示「提取中…」。
- [ ] **E3 对照题数**：核对提取出的题数与页面显示题数。
  - 预期：题数一致；若不一致，记录页面题数、实际题数与警告内容（如「标题显示共 N 题，实际解析 M 题」）。
- [ ] **E4 返回批量结果**：如果之前已有批量采集结果，点结果区右上角「返回批量结果」。
  - 预期：结果区回到整门课采集的题目列表。
- [ ] **E5 警告展示**：遇到有警告的页面时检查结果区。
  - 预期：警告以「⚠」小标签显示在题目行「质量 / 适配器」列，并在结果区提示条列出。

## F. 限速、超时与重试

- [ ] **F1 限速生效**：在「设置」→「采集设置」里把最小/最大请求间隔调大（如 1500 / 2500 ms），保存后采集 1 章，观察日志中相邻请求的时间间隔。
  - 预期：请求明显变慢，间隔符合设置。
- [ ] **F2 断网重试**：采集中途断开网络（关 Wi-Fi / 拔网线），观察日志与状态。
  - 预期：日志出现网络请求失败/重试记录；达到重试次数后该任务标记失败并继续，不会卡死、不会崩溃；恢复网络后可继续采集。
- [ ] **F3 超时生效**：把「单请求超时」调小到 `3000` ms（界面允许 1000～120000，实际请求下限为 3000 ms），开始采集。
  - 预期：日志出现「请求超时」相关记录，并按重试次数重试后标记失败。
- [ ] **F4 失败可诊断**：完成 F2/F3 后检查任务状态区与日志。
  - 预期：每个失败任务都有明确原因，任务状态区显示失败原因与源 URL。
- [ ] **F5 限流/风控识别**（可选）：如平台返回 429/403，检查暂停与提示。
  - 预期：日志提示「请求过于频繁（429）」或「请求被拒绝（403）」，工具暂停而不是继续硬闯。

## G. 运行控制

- [ ] **G1 暂停**：采集中点「暂停」。
  - 预期：状态变为暂停，进度和日志停止推进（不再发新请求）；已完成的结果保留。
- [ ] **G2 继续**：点「继续」。
  - 预期：从暂停处继续采集，日志出现「继续采集…」，轮询恢复。
- [ ] **G3 停止**：点「停止」。
  - 预期：提示「已停止采集」，采集结束后状态为完成/就绪，已采集结果可继续查看/导出。
- [ ] **G4 中断恢复**：暂停期间刷新学习通页面或 dashboard。
  - 预期：按界面提示重新连接后，能查看已有结果，且不会出现界面崩溃或重复加载。
- [ ] **G5 暂停原因提示**：观察因验证码/登录失效/网络导致的自动暂停。
  - 预期：顶部出现黄色提示条，文案分别为「检测到验证码…」「登录状态可能已失效…」「网络请求异常…」，处理后可点「继续」。

## H. 在线校对

- [ ] **H1 修改答案**：在结果区某题「正确答案」列行内修改，按回车或点开别处。
  - 预期：提示「答案已保存」；重新加载结果后答案仍是修改后的值；「已答」筛选状态同步。
- [ ] **H2 筛选/搜索**：用「章节」「题型」「已答」筛选，搜索题干关键词。
  - 预期：结果正确过滤，结果计数显示「x 题 · 筛选 y」。
- [ ] **H3 分页**：题目超过 50 题时翻页。
  - 预期：分页正常（每页 50 题），页码显示「第 x / y 页」，上一页/下一页按钮状态正确。
- [ ] **H4 来源链接**：点击结果表「来源」列的「打开」。
  - 预期：新标签页打开对应题目页（需已登录学习通）。

## I. 导出

> 每种导出都实际打开文件检查，不要只看「下载成功」。

- [ ] **I1 Markdown（含答案）**：点「Markdown（含答案）」。
  - 预期：下载 `xxt-<课程名>-题目-含答案-<日期时间>.md`；文件含标题、统计信息，按章节/题型分组，含我的答案、正确答案、解析（有的话）、来源与适配器；中文正常。
- [ ] **I2 Markdown（不含答案）**：点「Markdown（不含答案）」。
  - 预期：答案被隐藏，适合自测；其余内容完整，文件名含「不含答案」。
- [ ] **I3 JSON**：点「JSON」。
  - 预期：下载 `xxt-<课程名>-题目-<日期时间>.json`；文件结构含 `generator`、`schema`、`exportedAt`、`course`、`stats`、`tasks`、`questions`，题目数量与界面一致。
- [ ] **I4 CSV（Excel）**：点「CSV（Excel）」，用 Excel 打开。
  - 预期：下载 `xxt-<课程名>-题目-<日期时间>.csv`；中文不乱码（BOM 生效），列标题为序号/章节/题型/题干/选项/我的答案/正确答案/解析/知识点/来源链接/适配器/警告，行数正确。
- [ ] **I5 打印视图（含答案）**：勾选「打印包含答案」，点「打印视图」。
  - 预期：新窗口打开 A4 排版 HTML（标题「<课程名> · 题目打印视图」），含答案与解析，浏览器打印预览正常，可另存为 PDF。
- [ ] **I6 打印视图（不含答案）**：取消勾选「打印包含答案」再点「打印视图」。
  - 预期：答案隐藏，留出「我的答案：____」填空行。
- [ ] **I7 无结果时导出**：刷新后未采集时检查导出区。
  - 预期：导出按钮全部为灰色不可用（避免导出空文件）。

## J. 设置持久化

- [ ] **J1 修改设置**：点「设置」打开「采集设置」，修改最小/最大请求间隔、单请求超时、失败重试、单任务最大翻卡数，点「保存设置」。
  - 预期：提示「设置已保存」，弹窗关闭。
- [ ] **J2 持久化**：关闭 dashboard 标签页，重新通过扩展图标打开。
  - 预期：设置值仍为修改后的值（保存在 `chrome.storage.local`）。
- [ ] **J3 非法值校验**：输入非法值（如 minDelay 大于 maxDelay、retries 填 99）后保存。
  - 预期：弹窗内显示中文错误提示，不保存非法配置。
- [ ] **J4 恢复默认**：把设置改回默认值（600 / 1500 / 20000 / 2 / 80）并保存。
  - 预期：保存成功。

## K. 页面存档

- [ ] **K1 导出存档**：在课程页打开 dashboard，点顶栏「导出页面存档」。
  - 预期：提示「页面存档已导出：xxt-snapshot-….json」，浏览器下载该文件。
- [ ] **K2 内容检查**：用文本编辑器打开存档。
  - 预期：顶层含 `generator`、`exportedAt`、`course`、`state`、`snapshot`；`snapshot` 内含 `capturedAt`、`url`、`context`、`pageTitle`、`catalog`、`frames`、`extensionVersion`、`userAgent`，页面 HTML 非空。
- [ ] **K3 失败场景存档**：构造一次失败（如断网超时、或可复现的解析失败），失败后导出存档。
  - 预期：下载成功，`state.logs` 中包含对应失败日志。
- [ ] **K4 demo 模式存档**：在 `?demo=1` 下点「导出页面存档」。
  - 预期：可下载演示存档，不会报连接错误。

## L. 日志与状态展示

- [ ] **L1 日志滚动**：采集中观察日志区自动滚动、按级别着色、显示时间与级别。
  - 预期：滚动正常，最多保留最近 300 条，日志提示文案同步显示当前条数。
- [ ] **L2 状态一致性**：进度、统计、任务状态、日志四者一致。
  - 预期：不出现「已完成但统计为 0」之类的矛盾；扫描/采集中按钮可用状态正确（运行中不能重复开始）。
- [ ] **L3 连接断开提示**：采集中强制关闭学习通标签页。
  - 预期：3 次轮询失败后显示「与页面的连接断开，请刷新学习通页面后重新连接」，停止轮询。

## M. 开发者自测（可选）

- [ ] **M1 demo 模式**：打开 `chrome-extension://<扩展ID>/dashboard/dashboard.html?demo=1`。
  - 预期：顶部显示 demo 横幅；所有区块用内置示例数据渲染，可演示扫描、采集、暂停/继续/停止、单页提取、校对与全部导出。
- [ ] **M2 无外部请求**：开发者工具 Network 里确认没有 CDN / 远程脚本请求。

- [ ] **M3 控制台无报错**：全程观察扩展页面与学习通页面的开发者工具 Console。
  - 预期：无未捕获异常（与网络失败相关的常规日志除外）。
- [ ] **M4 开发仓库离线自测（仅开发者，非用户步骤）**：在开发仓库中打开 `tools/parser-test.html` 与 `tools/dashboard-test.html`。
  - 预期：解析器断言（含判断题页、隐藏旧题不污染结果等回归）与 dashboard demo 断言全部通过。打包后的扩展包不包含 `tools/`，用户无需执行此项。

## 通过标准

- **A / B / C / I / J / K 全部通过**是发布的最低要求；
- D、E、F、G、H、L、M 中允许出现**已知限制内**的失败（如平台无答案、加密字体页面、网络环境特殊），但必须有明确原因和日志，不能静默丢数据；
- 每一条失败都要记录：编号、现象、日志、以及（必要时）页面存档，便于后续修复。

## 发现问题时怎么反馈

1. 记录失败的清单编号（如 `C2`、`F3`）与现象；
2. 复制 dashboard 日志区相关日志（含时间、级别、完整文字）；
3. 按 [SNAPSHOT.md](SNAPSHOT.md) 导出页面存档 JSON；
4. 附上第 0 节的环境信息；
5. 注意：存档可能含课程内容与个人信息，请只私下发送给维护者。
